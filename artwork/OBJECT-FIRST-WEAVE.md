# Object-First Weave 01

`object-first-weave-01.svg`, the packaged wallpaper, and the theme preview are generated by `render-object-first-weave.py` from a deterministic original point field.

The source uses a middle neutral ground and balanced low-contrast hard-edged marks. Points are distributed on a toroidal plane so the edges have the same density as the center, and horizontal, vertical, and square marks are balanced to prevent directional drift. It is a single aperiodic field, not a repeated tile.

The source contains no extracted system patterns, period icons, logos, device silhouettes, filters, transparency, gradients, text, grain, or embedded images. It does not reproduce the original Macintosh 8x8 desktop tiles.

Regenerate the assets from the repository root with:

```bash
python3 artwork/render-object-first-weave.py
python3 artwork/render-crop-proof.py
```

`themes/alumina-raster/preview.png` is a wallpaper-only picker preview rendered with Lanczos filtering. It is not a runtime screenshot. `docs/wallpaper-crop-proof.png` is labeled outside its image frames and contains no simulated shell UI.
