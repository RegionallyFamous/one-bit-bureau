# Registration Sheet 01

`registration-sheet-01.svg`, the packaged wallpaper, and the theme preview are generated by `render-registration-sheet.py` from an original two-color mask.

The source uses only integer rectangles: a quiet paper field, one registration rule, and a coarse square-mark spine on the right. It contains no extracted system patterns, period icons, logos, device silhouettes, filters, transparency, gradients, grain, or embedded images.

Regenerate the assets from the repository root with:

```bash
python3 artwork/render-registration-sheet.py
python3 artwork/render-crop-proof.py
```

`themes/alumina-raster/preview.png` is a wallpaper-only picker preview. It is not a runtime screenshot.
`docs/wallpaper-crop-proof.png` is labeled outside the image frames and contains no simulated shell UI.
