# Alumina Raster artwork

The Raster edition uses one original procedural background family instead of illustrative wallpaper.

- `registration-sheet-01.svg` is the deterministic vector master.
- `render-registration-sheet.py` generates the packaged 3840x2160 wallpaper and 1600x900 wallpaper-only picker preview.
- `render-crop-proof.py` generates the labeled multi-aspect wallpaper crop proof.
- `REGISTRATION-SHEET.md` records the provenance and regeneration contract.

The preserved modern edition's source artwork remains in this branch for Git continuity but is not installed by `setup` and is not part of the Raster theme.
