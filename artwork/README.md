# Wallpaper provenance

The Alumina dark and light wallpaper masters are original assets generated for this project with Codex's built-in Imagegen workflow on 2026-08-29. They do not use input images or Apple assets.

The built-in tool returned 1672×941 PNG sources. Those source images are preserved in this directory. The installable theme derivatives were resized with Lanczos filtering to 3840×2160 and stripped of ancillary metadata; 1600×900 derivatives serve as provisional theme-picker previews.

## Dark prompt

```text
Use case: stylized-concept
Asset type: 16:9 desktop wallpaper for an Omarchy theme, final-quality landscape bitmap
Primary request: create an original abstract wallpaper for a dark “aluminum glass” Linux desktop experience inspired by the calm material depth of premium desktop operating systems, without imitating any existing Apple/macOS wallpaper
Scene/backdrop: deep graphite-to-midnight-blue field with one large flowing translucent glass ribbon and a restrained cobalt-to-violet light bloom
Style/medium: ultra-clean abstract 3D material study, soft frosted glass, anodized aluminum sheen, subtle volumetric depth, premium but quiet
Composition/framing: 16:9 wide composition; visual mass concentrated toward the lower-right and center; generous clean negative space across the upper-left for desktop icons and top bar; no hard horizon
Lighting/mood: soft studio light, calm, precise, understated
Color palette: graphite #111318, cool slate #252A33, restrained blue #3B82F6, soft violet #7C6FF2, small icy highlights
Materials/textures: smooth glass and satin metal only; no noise, grain, paper, fabric, or photographic objects
Constraints: no text, no logo, no Apple mark, no recognizable macOS wallpaper composition, no UI elements, no device mockup, no watermark; keep icon-legibility zones uncluttered; edges must remain visually calm for cropping across 16:9 and ultrawide displays
```

Materials/textures: smooth glass and satin metal only; no noise, grain, paper, fabric, or photographic objects
